Technical requirements:

1. Frontend architecture

* Keep the app as a SPA-style flow where possible.
* Do not trigger full page reloads for normal actions.
* Use component/state updates and API mutations for all admin changes.
* Use loading skeletons/spinners only where needed.
* Keep UI responsive and lightweight.
* Use memoization / lazy loading for heavy lists like ads, products, activity, transactions, and analytics.
* Keep the fixed header, bottom nav, and back button behavior stable across all pages.

2. Backend architecture

* All admin changes must be saved in the database immediately and reflected in the user panel in real time.
* Use one source of truth for:

  * users
  * roles
  * wallets
  * deposits/withdrawals
  * ads/packages/menu items
  * platform settings
  * support contacts
  * notifications
  * activity feed
  * language/theme settings
  * task assignments
  * extra task approvals
  * platform branding
* Do not hardcode values that should be admin-managed.
* Keep every setting persistent after refresh, logout, or new login.

3. Database structure
   Create or map tables/collections logically for:

* users: username, email, password hash, status, role, country if needed only in admin, referral/team code, assigned wallet, assigned package/menu/platform, balance
* wallets: wallet name, address/link, active/inactive, assigned users
* transactions: type, amount, status, source wallet, target wallet, timestamp, userId, admin note
* ads: setCode, adCode, title, imageUrl, contentUrl, amount, commission, afterCommission, depositRequired, depositAmount, isActive, platform
* tasks/assignments: userId, platform, adCode, status, progress, balance check, approval state
* platform settings: platform name, commission range, description, logo, enabled, visibility
* support contacts: type, title, link, icon, enabled, priority
* notifications: recipient, title, body, type, read/unread, deleted, createdAt
* activity feed: masked name, action type, amount, timestamp, region label, visibleOnHomeOnly
* ui settings: theme, language, device view toggle, visibility toggles
* admin audit log: who changed what and when

* When a notification is deleted, it must disappear everywhere immediately.

* When a task is assigned, the user must see it instantly.
