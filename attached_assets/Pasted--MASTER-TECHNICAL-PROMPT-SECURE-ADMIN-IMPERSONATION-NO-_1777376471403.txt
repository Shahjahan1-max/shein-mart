**MASTER TECHNICAL PROMPT — SECURE ADMIN IMPERSONATION (NO PASSWORD ACCESS, FULL CONTROL, AUDITABLE)**

Work ONLY on the existing codebase. Do NOT rebuild. Do NOT expose or store user passwords. Do NOT suppress security events.

---

# 1) OBJECTIVE

Allow **Super Admin** to access a user account **without password** via a controlled, auditable **Impersonation** flow. Admin can perform all user actions, but the system remains **traceable, time-limited, and secure**.

---

# 2) NON-NEGOTIABLE SECURITY RULES

* Passwords hashed with **bcrypt** only; never readable or returned.
* All impersonation sessions are **time-limited** and **revocable**.
* All actions during impersonation are **logged** with adminId + userId.
* Security events are **not suppressed**. Use “support activity” messaging (not “new login alert”) if you differentiate.
* UI must show a **visible banner** during impersonation with an **Exit** action.

---

# 4) AUTH TOKEN DESIGN (JWT)

## 4.1 Claims

```js id="p2a1"

  userId: "<targetUserId>",
  role: "user",
  isImpersonated: true,
  adminId: "<adminId>",
  jti: "<uuid>",
  exp: "<+60m>"
}
```

* Sign with `JWT_SECRET`
* Short TTL (30–60 min)
* `jti` stored in `admin_sessions`

# 5) BACKEND — ENDPOINTS

## 5.1 Start Impersonation (Super Admin Only)

**POST** `/api/admin/impersonate`

```js id="p3a1"
// guards: auth + role === 'super_admin'
const { userId } = req.body;

// generate jti
const jti = crypto.randomUUID();

const token = jwt.sign(
  { userId, role: "user", isImpersonated: true, adminId: req.user.id, jti },
  process.env.JWT_SECRET,
  { expiresIn: "60m" }
);

// persist session
await AdminSession.create({
  adminId: req.user.id,
  userId,
  tokenId: jti,
  createdAt: new Date(),
  expiresAt: new Date(Date.now() + 60*60*1000),
  revoked: false,
  ip: req.ip,
  userAgent: req.headers["user-agent"]
});

// audit log
await AdminLog.create({
  adminId: req.user.id,
  userId,
  action: "IMPERSONATE_START",
  timestamp: new Date()
});

return res.json({ token });
```

---

## 5.2 Stop Impersonation

**POST** `/api/admin/stop-impersonation`

```js id="p3a2"
// revoke current jti
await AdminSession.updateOne(
  { tokenId: req.token.jti },
  { $set: { revoked: true } }
);

await AdminLog.create({
  adminId: req.token.adminId,
  userId: req.token.userId,
  action: "IMPERSONATE_END",
  timestamp: new Date()
});

return res.json({ ok: true });
```

## 5.3 Auth Middleware (UPDATE)

```js id="p3a3"
const decoded = jwt.verify(token, SECRET);

// common
req.userId = decoded.userId;
req.role = decoded.role;

// impersonation branch
if (decoded.isImpersonated) {
  // check session validity
  const session = await AdminSession.findOne({ tokenId: decoded.jti });
  if (!session || session.revoked || session.expiresAt < new Date()) {
    return res.status(401).json({ message: "Impersonation expired/revoked" });
  }

  req.isImpersonated = true;
  req.adminId = decoded.adminId;
}
```
